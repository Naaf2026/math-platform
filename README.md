# FAHI VISSNUN Math Learning Platform

A KooBits-inspired mathematics learning platform MVP for FAHI VISSNUN Learning Institute.

## Phase 1 — Foundation

- Next.js App Router + TypeScript
- Tailwind CSS
- Responsive student-first homepage
- FAHI VISSNUN visual identity
- Clean foundation for lessons, practice, mastery and dashboards

## Roadmap

1. Foundation and responsive shell
2. Student accounts and Supabase data model
3. Practice engine and question bank
4. Progress, mastery and student dashboard
5. Teacher/admin tools
6. Gamification and rewards
7. Cloudflare production deployment

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Important

Environment variables and service credentials will be added only when the corresponding Supabase phase begins. Never commit Supabase service-role keys or other secrets.
